## What's new

- **Add a live station.** On the Recordings screen, enter the address of a Wildlife Network Base or a BirdNET-Go station on the same network and choose the days: Studio reads its detections into the project, and Review fetches each clip from the station the first time you play it (then keeps it with the project). Check them in Review, then export or publish your answers as usual. Refresh adds only the detections made since the last import, and nothing is added twice. Studio only reads from the station and works with it only while it is on the same network. BirdNET-Pi has no stable read API, so it is not supported live: copy its files and use Import results.
