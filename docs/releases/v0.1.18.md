## What's new

- **A Base that moves starts a new deployment.** When your Wildlife Network Base reports a new place (more than about 1 km from where it was), the next Refresh files its new detections under a new deployment at the new place, named for example "Hill top (moved 20 Nov 2026)". Detections imported before keep the old place, so exports to GBIF and Wildlife Network show each detection where it was heard. The station list on the Recordings screen notes the day the move was noticed. Small changes, such as picking the same spot again on the map, keep the same deployment. If the Base had no place before, the first one it reports fills in the existing deployment.
- **Add a folder reads AAC clips.** Folders with .m4a or .aac files, such as clips copied from a Base, are now read like WAV, FLAC and MP3 recordings.
