## What's new

- **Intel Macs**: a separate download for Macs with an Intel processor, signed and notarized like the Apple Silicon one.
- **Disk space**: Studio estimates the space Perch needs next to the project, warns when the disk is too small, and stops before the next recording if less than 1 GB is free.
- **History** now also records exports, publishing, scans and training done with the `wlnw` command line.
- **Security**: damaged audio files with impossible sample rates are rejected, a crash on one recording no longer leaves Studio stuck, the dataset id is checked before an upload key is sent, release builds only load models from Studio's own folders, and the map picker uses MapLibre 6.
