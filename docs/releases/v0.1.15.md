## What's new

- **Publishing to Wildlife Network is simpler.** Studio now sends your dataset's title, people to credit, institution, description and licence along with the records, so you no longer type them again on wlnw.org.
- **Studio remembers your dataset.** The Publish screen fills in the dataset id you used last time. The upload key is still never stored, so paste it each time.
- **Add more records later.** You can send the next SD card to a dataset you already submitted. It goes back to draft on wlnw.org until you submit it again.
- **Clearer report after sending.** Studio says how many detections were left out because a recorder or camera has no place or the file has no time, links to your dataset on wlnw.org, and says where the records will show up.
- **First run.** If no model is installed yet, the Find species screen now tells you to download one (start with Perch) instead of showing a greyed-out Start button.
- **Sharing problems are shown.** If sharing your checked answers fails, for example when you are offline, Settings now says so and Studio tries again later.
