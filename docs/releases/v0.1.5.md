## What's new

- **Faster on Mac**: processing now runs on the fast cores and is no longer slowed down when Studio is in the background.
- **Help and feedback**: "Help and how-to guides" opens the Studio guides on wlnw.org, and "Send feedback or report a problem" opens a short form, with the app version filled in.
- **Update check**: Studio now checks for updates through wlnw.org (GitHub if that cannot be reached). It sends only the app version and system, so we can count how many copies are in use. Nothing about your recordings or results is sent.
