## What's new

- **Files**: every recording in a project with its status per model (done, partly done, to do, could not be read), the reason a file could not be read, retry for one or all failed files, search, a recorder filter, and the whole list saved as CSV.
- **History**: every processing run (models, recordings, hours of audio, new detections, speed, finished or paused), folders added, classifier training, exports and publishing, saved inside the project file.
- Command line: `wlnw files`, `wlnw retry` and `wlnw history`.
