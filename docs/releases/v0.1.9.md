## What's new

- **SpeciesNet in one click**: the camera-trap model (SpeciesNet with MegaDetector v6) now downloads from the Find species screen, about 250 MB. No more adding it from a folder.
- **How each record was identified**: every Darwin Core and CSV export now says which model found it and its score, whether a reviewer confirmed it, and how the species threshold was set (fitted from your reviews, with how many clips and the estimated precision, or the default), plus the Studio version. Data centres and GBIF users can judge each record.
