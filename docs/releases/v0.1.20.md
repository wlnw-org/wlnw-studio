## What's new

- **Remove recorders, stations and recordings from a project.** On the Recordings screen each recorder and each live station now has a Remove button, and on the Files screen each recording has one. Studio first shows how many recordings, detections and review answers will go, and asks before removing anything. Only Studio's own records are removed (detections, review answers, Perch results and named examples for those recordings). The audio files stay on your disk: add the folder again to bring them back, then process them again. Removing a live station also deletes the clips Studio fetched from it and kept next to the project; nothing is changed on the station. Thresholds fitted from your answers are fitted again from the answers left. Each removal is listed on the History screen.

## What's fixed

- **Review no longer freezes the window on Linux.** Lists, answers and other project work now run in the background instead of on the window's own thread, so a big project (for example after Perch has found thousands of species) no longer stops the window from responding. The species list on the Review screen is also faster to load, and opening a project never waits for a run in progress.
- **Spectrograms on Linux.** Very long clips are drawn at most 4,000 columns wide, clips play from memory in a way WebKitGTK handles better, and Studio turns off WebKitGTK's DMA-BUF renderer, which leaves the window blank or frozen with some graphics drivers. To turn it back on, start Studio with WEBKIT_DISABLE_DMABUF_RENDERER=0. If the window still freezes, try starting Studio with WEBKIT_DISABLE_COMPOSITING_MODE=1 and let us know through Help and feedback.
